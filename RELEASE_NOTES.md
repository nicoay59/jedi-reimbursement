# Release Notes — Reimbursement Portal 1.2.0

## Status

```text
Corporate Professional Build
```

## Ringkasan

Versi 1.2.0 menyempurnakan tampilan aplikasi agar lebih profesional untuk
penggunaan internal PT. Jedi Global Teknologi. Seluruh aturan bisnis dan fitur
versi 1.1.1 tetap dipertahankan.

## Pembaruan antarmuka

- Corporate dark navigation dengan indikator halaman aktif.
- Identitas aplikasi `Reimbursement Portal` dan monogram `JDI`.
- Halaman login enterprise dengan informasi keamanan.
- Dashboard karyawan berbasis ikon dan layanan yang lebih terstruktur.
- Dashboard administrator dengan kartu statistik yang lebih jelas.
- Gaya form, tabel, badge, alert, timeline, dan laporan yang konsisten.
- Footer internal perusahaan.
- Tampilan responsif dan dukungan reduced motion.

## Kebijakan klaim parkir

- Satu pengajuan maksimal satu bulan kalender.
- Maksimal Rp200.000 per pengajuan.
- Bulan berbeda diajukan secara terpisah.
- Periode maksimal tiga bulan sebelumnya.

## Kompatibilitas

- Backend Golang tetap kompatibel.
- Database dan migration tidak berubah dari versi 1.1.1.
- Docker Compose dan script Windows tetap digunakan.
